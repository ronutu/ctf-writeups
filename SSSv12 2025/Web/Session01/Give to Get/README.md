# Give to Get

## Description

Get the flag from [give-to-get](http://141.85.224.70:8084/give-to-get/).

## Intuition

We try entering parameteres in the URL.

## Solution

This URL reveals the flag:

```bash
http://141.85.224.70:8084/give-to-get/?ask=flag
```

## Flag

`SSS_CTF{giving_is_receiving}`
