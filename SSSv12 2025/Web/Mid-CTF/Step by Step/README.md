## Solution

There is a text on the main page hinting us to look for a hidden page.

```
Usually, you have to pay in order to see this HTML file. However, today is your lucky day.

We are giving you a free version for a limited amount of time.

Its filename should be quite easy to guess.
```

After multiple tries, we found out that the page they were reffering to was `trial.html`.

On the page we have to guess every char of the flag so we create a Python script to automate this task.

This worked flawlessly during the contest. Unfortunately, the staff rotated the challenge to a new port after the CTF ended, so our original script no longer connects. Because of that we can’t reproduce the full flag here.
