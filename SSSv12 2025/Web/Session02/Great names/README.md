# Great names

## Description

Get the flag from [great-names](http://141.85.224.70:8080/).

## Intuition

We look in the cookies.

## Solution

There is a cookie for `marco` and we need to put `polo`.

There is a another cookie for `fernando` and we need to put `magellan`.

There is a another cookie for `cristofor` and we need to put `columb` and we find the flag.
